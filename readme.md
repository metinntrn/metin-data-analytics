# 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/metinntrn/data-science.git

cd data-science
```

Install dependencies:

```bash
pip install -r requirements.txt
```

For dashboard projects:

```bash
streamlit run main.py
```

For notebook projects:

```bash
jupyter notebook
```
